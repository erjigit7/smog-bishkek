# Контекст проекта

Решения и исследование, сделанные до первого кода. Читать перед тем, как менять направление проекта.

## Автор и цель
Программный инженер из Бишкека. Цель — сделать программу, полезную городу. Проект ведётся в Claude Code: тяжёлые задачи в облачных сессиях, обучение и мелкие задачи в локальном CLI.

## Почему именно прогноз смога
Рассматривались и отклонены:
- **Пробки / светофоры.** Данные 2GIS/Google дают скорости, а не объёмы потоков; доступа к контроллерам нет; в городе уже есть АСУДД («умные светофоры», пилот на 21 перекрёстке). Google ToS запрещает хранить время в пути дольше 30 дней.
- **Трекинг автобусов** — уже есть в приложении мэрии «Мой город».
- **Жалобы жителей, совместные поездки** — зависят от других людей и сети пользователей.
- **Анализ госзакупок** — открытые данные OCDS не обновляются с сентября 2022; закон 2022 г. вывел ~1/3 расходов из публикации; Kloop уже делает red flags для журналистов.
- **Проверка застройщиков** — реально (реестр Минстроя, ~5 400 объектов, без API), оставлена вторым проектом на потом.

## Аналоги прогноза смога и чем мы отличаемся
- IQAir, AccuWeather, weather.com — прогноз на глобальных моделях, не калиброван под Бишкек.
- MoveGreen (aq.kg, aba.kg) — сеть датчиков, показывает текущее состояние, без прогноза.
- Научные статьи (Random Forest, XGBoost для Бишкека) — исследования, не продукт.
- GitHub `Ashymov-iHub/Breathe-Bishkek` — сбор почасовых данных с августа 2026, прогноза нет. Возможный партнёр.

**Наше отличие:** локальная модель, которая бьёт глобальную (см. baseline в CLAUDE.md), простой продукт в Telegram на русском и кыргызском, позже — по районам.

## Проверенные источники данных (29.09.2026)
| Источник | Доступ | Заметки |
|---|---|---|
| sensor.community live API | без ключа | 5 PM-датчиков в радиусе 15 км, SDS011 |
| sensor.community archive | без ключа | зимы 2022/23–2025/26: 11 SDS011 в Бишкеке за всё время, 3–10 в день (30.09.2026, `smog.find_sensors`) |
| Open-Meteo archive (ERA5) | без ключа | есть boundary_layer_height — ключевой признак инверсий |
| Open-Meteo air quality (CAMS) | без ключа | baseline; сильно занижает зимний смог |
| aqicn / WAQI | нужен бесплатный токен | demo-токен отдаёт Шанхай, не Бишкек |
| OpenAQ v3 | нужен ключ | не проверен |
| MoveGreen | сайт отвечает | API не изучен — следующий кандидат, у них больше датчиков |

## Известные ограничения
- Мало датчиков: 3–10 в день, и с каждым годом меньше (2022/23: 6–10, 2025/26: 3–5) — модель пока городская, не районная.
- SDS011 завышает PM при влажности > ~70% — нужна поправка.
- Датчик 34313 (запад города) показывает заметно выше остальных: разные районы действительно различаются, но нужна проверка на неисправность.
