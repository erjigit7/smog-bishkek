# smog-bishkek

Открытый прогноз загрязнения воздуха (PM2.5) для Бишкека на 1–3 дня вперёд.

## Зачем
Глобальные модели, на которых работают многие погодные приложения, почти не видят зимний смог Бишкека.
Сравнение с реальными датчиками за зиму 2025/26:

| | Датчики | Глобальная модель CAMS |
|---|---|---|
| Средний PM2.5 | 51 мкг/м³ | 18 мкг/м³ |
| Та же категория качества воздуха | — | 35% часов |
| Пойманы «вредные» часы (≥ 55 мкг/м³) | 916 | **0** |

## Быстрый старт
Нужен только Python 3.10+.
```
py -m smog.backfill --start 2025-11-01 --end 2026-02-28
py -m smog.evaluate_cams --start 2025-11-01 --end 2026-02-28
```

## Данные
- [sensor.community](https://sensor.community) — народные датчики PM2.5
- [Open-Meteo](https://open-meteo.com) — погода (ERA5) и глобальная модель CAMS
